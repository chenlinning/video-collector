# Project Environment Instructions

## Dependency Management

- Most machine-level dependencies are stored under `D:\Program Files`.
- Before using or installing a dependency, check `D:\Program Files` first.
- Reuse an existing dependency directly when available.
- Install a missing dependency under `D:\Program Files`.
- Keep different dependencies in separate, clearly named subdirectories.

## Cache Management

- Create a `cache` directory in the project root whenever project caching is needed.
- Store all cache data generated by this project inside that project-local `cache` directory.
- Do not place project cache data elsewhere on the machine.

## Production Deployment Target

- The only authorized production server public IPv4 address is `47.251.87.147`.
- The canonical production URL is `https://video-collector.ximoai.cn`.
- Do not deploy this project to another server or use another production hostname unless the user explicitly changes this requirement.
